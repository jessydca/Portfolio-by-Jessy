PORTFOLIO JESSY DUCA — mise en ligne sur GitHub Pages
=====================================================

Contenu du dossier
  index.html   la page du site
  images/      toutes les planches, photos et illustrations
  models/      les deux maquettes 3D (Pôle balnéaire, Centre communautaire)

Première mise en ligne
  1. Créer un compte gratuit sur https://github.com (retenir son nom d'utilisateur).
  2. Cliquer sur « + » en haut à droite, puis « New repository ».
  3. Nommer le dépôt exactement : NOM-UTILISATEUR.github.io (en minuscules),
     cocher « Public », puis « Create repository ».
  4. Sur la page du dépôt, cliquer sur « uploading an existing file ».
  5. Glisser-déposer index.html ET les dossiers images et models
     (le contenu de ce dossier, pas le dossier lui-même), puis « Commit changes ».
  6. Aller dans Settings > Pages : Source « Deploy from a branch »,
     branche « main », dossier « / (root) », puis « Save ».
  7. Patienter 1 à 2 minutes : le site est en ligne à l'adresse
     https://NOM-UTILISATEUR.github.io

Mises à jour
  Refaire l'étape 4 et 5 avec les nouveaux fichiers : GitHub remplace les anciens.

À savoir
  - Ouvert directement depuis l'ordinateur (double-clic sur index.html), le site
    s'affiche mais les maquettes 3D ne se chargent pas : c'est normal, elles
    fonctionnent une fois le site en ligne.
